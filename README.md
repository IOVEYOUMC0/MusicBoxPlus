# MusicBox
**This fork of MusicBox requires a custom fork of NoteBlockAPI's 2.0 branch!** https://github.com/DaringShepard/NoteBlockAPI | A download is provided with MusicBox in the [releases section](https://github.com/DaringShepard/NoteBlockAPI/releases). 
> Original plugin: [https://github.com/Spliterash/MusicBox](https://github.com/Spliterash/MusicBox)

This plugin adds in the ability to play [NBS songs](https://opennbs.org/) through records, signs, and/or through a GUI menu on Spigot servers! A full and proper description can be found on the original author's [Spigot page](https://www.spigotmc.org/resources/musicbox-custom-noteblockmusic-on-discs.67949/).
